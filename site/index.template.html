Install: open the APK on the phone → allow "Install unknown apps" for your browser if asked → Install. Then log in with the username and password the admin gave you, and allow the Phone and Call log permissions.

What it does

  • Admin: upload client numbers from Excel/CSV (duplicates removed), give them to callers by hand or share equally, add / deactivate callers and log them out.
  • Caller app: their list, one-tap call, and the app checks each call in the phone's call history — number, time, talk time, connected or not. Works offline and syncs later.
  • After each call: Interested / Not interested / Callback / Wrong number / Not reachable + note.
  • Payout: set ₹ per counted call and ₹ per interested lead separately, plus the minimum talk time. Daily and monthly totals per caller, adjustments with a reason, approve and mark paid.
  • Anti-fraud: only assigned numbers count, repeat calls to the same number count once, short and same-time calls don't count, suspicious patterns are flagged. Every call shows "counted / not counted + reason".
  • Dashboard (today / 7 days / month), leads list with follow-up reminders, Excel and PDF export.

New in v1.1

  • Caller account: username, wallet (earned / approved / pending / withdrawn / available), payment details (UPI or bank, shown masked), withdrawals with a 16-hour payment timer.
  • Admin payments: withdrawal queue with overdue highlighting, UPI QR code + payment link for each request, mark paid with reference, Excel export. The app does not move money — you pay in your own UPI / bank app.
  • Callbacks: a client you called from the app who calls back from the same number is attached to that client as "Callback received".
  • Logs: call details are removed from the caller's phone after a retention period (the server keeps everything); callers can request old logs with a purpose and you approve. Daily and all-time log files (Excel + CSV).
  • Terms & Conditions controlled by the admin: versioned, callers must accept the current version, acceptance report.
  • Streak with a daily task target, Help chat inside the app, and a refreshed layout.

New in v1.2

  • Upload client numbers from any Excel or CSV file: the app finds the phone-number column itself, shows a preview (new, already in the list, repeated, skipped), then imports. You can change the columns before importing.
  • Skipped rows (landlines, numbers that are not 10-digit mobiles, rows without a number) can be downloaded as a list.
  • Undo an upload while none of its numbers has been called. Name, address, source and notes columns are kept with each number.

Calls are not recorded. The app reads the phone's call history only for calls placed from the app. Because it reads the call log, this app is shared as an APK link rather than on the Play Store.
