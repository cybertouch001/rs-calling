Install: open the APK on the phone → allow "Install unknown apps" for your browser if asked → Install. Then log in with the username and password the admin gave you, and allow the Phone and Call log permissions.

What it does

  • Admin: upload client numbers from Excel/CSV (duplicates removed), give them to callers by hand or share equally, add / deactivate callers and log them out.
  • Caller app: their list, one-tap call, and the app checks each call in the phone's call history — number, time, talk time, connected or not. Works offline and syncs later.
  • After each call: Interested / Not interested / Callback / Wrong number / Not reachable + note.
  • Payout: set ₹ per counted call and ₹ per interested lead separately, plus the minimum talk time. Daily and monthly totals per caller, adjustments with a reason, approve and mark paid.
  • Anti-fraud: only assigned numbers count, repeat calls to the same number count once, short and same-time calls don't count, suspicious patterns are flagged. Every call shows "counted / not counted + reason".
  • Dashboard (today / 7 days / month), leads list with follow-up reminders, Excel and PDF export.

Calls are not recorded. The app reads the phone's call history only for calls placed from the app. Because it reads the call log, this app is shared as an APK link rather than on the Play Store.
